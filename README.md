# GrowthSEO — releases

Public download host for the GrowthSEO desktop app. Source lives in a private
repository; only the built installers are published here.

The binary is inert without a licence key — the app refuses to run until it is
activated against the licensing service — so the download itself does not need
to be gated.

Get a licence key from your AppSumo purchase, then enter it on first run.
